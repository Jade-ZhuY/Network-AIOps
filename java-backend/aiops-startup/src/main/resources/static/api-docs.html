Network AIOps Java 业务 API

所有 /api/v1 接口（health 除外）需要 Authorization: Bearer TOKEN。参数和完整契约见仓库 docs/java-backend.md。

  • GET /api/v1/me — 当前身份
  • GET /api/v1/workspace — 能力声明
  • GET /api/v1/business/overview — 当前身份业务总览
  • GET / POST /api/v1/tickets — 分页查询 / 新建
  • GET / PUT / DELETE /api/v1/tickets/{id} — 详情 / 修改 / 软删除
  • PATCH /api/v1/tickets/{id}/status — 受控状态流转
  • GET /api/v1/tickets/{id}/events — 处理历史
  • GET / POST /api/v1/tickets/{id}/analyses — 分析记录 / 调用 Agent
  • GET /api/v1/admin/audit — 当前身份范围业务审计（管理员）

监控与指标

  • GET /api/v1/monitor-templates — 监控类型模板清单（YAML 定义）
  • GET /api/v1/monitor-templates/{type} — 模板详情（指标、默认阈值）
  • GET / POST /api/v1/monitors — 监控对象分页查询 / 新建
  • GET / PUT / DELETE /api/v1/monitors/{id} — 详情 / 修改 / 软删除
  • GET /api/v1/metric-definitions — 指标定义（跨模板聚合）
  • GET /api/v1/monitors/{id}/metrics/{metricId}/series?start=—end= — 指标时序查询（只读演示库，窗口 ≤31 天，空窗口返回 no_data）

Java 业务独立运行。Agent 未启用或不可达时返回明确的 503，不生成模拟报告。
